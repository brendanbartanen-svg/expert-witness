# Pre-reports

A pre-report is the report with the answers blank: the questions an editor,
referee, or reader wants answered from a paper's code and data, each
specified so that two people would compute the same number, with the
resolution stated in both directions before anyone has seen the answer. It is
committed to a repository the authors, the editor, and the requester can
read before the witness runs. See `../expert-witness/assets/PRE-REPORT-TEMPLATE.md`.

| Folder | Paper | Requester | Status |
|---|---|---|---|
| `2026-10-liu-et-al-ai-tutoring/` | Liu et al. (2026), *The Effects of Course-Integrated AI Tutoring on Student Performance and Engagement: A Randomized University Trial*, EdWorkingPaper 26-1598 | Brendan Bartanen (reader) | Offered to the authors; no run yet |

A pre-report in this folder is an open request. It becomes a run when a host
commits a `HOST.md` beside it in a private repository and runs the skill.
